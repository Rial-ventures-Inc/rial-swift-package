# RialSDK

Swift SDK for integrating [rial](https://get-rial.com) photo verification —
capture, hardware attestation, and result handling — into an iOS app.
Distributed as a compiled binary (XCFramework); no source in this repo.

## Install

```swift
.package(url: "https://github.com/Rial-ventures-Inc/rial-swift-package", from: "0.10.2")
```
